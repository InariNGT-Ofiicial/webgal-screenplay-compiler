# 生产层协作约定

先读 [架构](../docs/architecture.md) 与 [接驳说明](../docs/production-integration.md)。

- 编译器产物以原生 `game/` 目录为交接点；默认导入逐字节保留所有源文件。
- 转义只使用 `src/script.mjs` 的 `escapeText`。文字切分与内容锚点仍使用 `compiler/` 的既有实现；不得另写一套。
- 自动存档只能显式启用，章末锚点必须唯一匹配。新增指令前要求更换 Game_key。
- 使用原生场景、菜单和存档；不修改上游 bundle，不发送剧情注入指令，不实现另一份 UI 或存档格式。
- 所有删除与覆盖必须受自有清单和路径检查约束；安装必须可回退。
- 作品正文、原角色、美术、音频、截图、个人路径与凭据不得提交。示例通过生成器重建。
- 修改后在仓库根运行 `npm test` 和 `npm run check`。涉及保存时序、HTTP 或 DOM 的改动还需真实浏览器验收。
