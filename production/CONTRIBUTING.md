# 贡献

用 Node.js 22 或更新版本运行 `npm test`、`npm run check`、`npm run demo`。修改运行时适配时另跑示例浏览器验收。

保持原生 WebGAL 的渲染与存档职责；优先通过配置、原生脚本、主题 CSS 和官方预览协议适配。源正文和显示修订分开，所有修订有审计记录。不要增加原作品名称、正文、美术、参考音频或个人缓存路径作为测试夹具。

修改配置契约时更新示例与文档，增加版本号或明确兼容行为。涉及正文、锚点、人物现场记忆、转义或存读档的修改应有可失败的回归样例。

提交前执行 `git add` 后再运行索引审计，并人工通读注释和示例。生成物、下载的引擎、浏览器和游戏素材放在被忽略的目录。
