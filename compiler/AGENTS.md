## ★ 不变量（唯一实现 / 唯一真源）—— 动之前先看这张表

| 事实 | 唯一出处 | 违反的后果 |
|---|---|---|
| **文本框几何** | `textbox.mjs`（画布 2560×1440 / 内容区 2022×234px / 字号 52.48px / 行高 2.2em ⇒ 每行 35 全角字 × 2 行 = 上限 70）。`MAX_BOX`/`MIN_BOX`/体检阈值全从它派生 | 阈值散落多处后必然漂移，而**漂移不报错**。★ **真机实测，不许读 SCSS 猜** |
| **文本断框** | `text-split.mjs` 的 `chooseCut` —— 一次满足全部约束（句末标点 / 词边界 / 框尾不许 `，、；：` / 框尾不许开引号 / 框尾·框首不许单字虚词 / 防孤字） | 同上。**只允许有这一份实现** |
| **编辑层表述** | `editorial.mjs` —— 转换器丢弃 + `build-demo` 编译期拦截 + 测试共用 | ★ **不能按「被【】包住」一刀切**（叙事内方括号很多），误判 = 剧本丢台词 |
| **WebGAL 脚本转义** | `../production/src/script.mjs` 的 `escapeText`，`build-demo.mjs` 共用（6 个字符：`\` `;` `:` `\|` `{` `}`） | 症状是「某几句台词莫名被截断」，而这个症状**不会指向转义层** |
| **剧情锚点** | `anchor.mjs` —— 按内容子串匹配，**不依赖断框** | 反过来依赖断框 ⇒ 改一次切分全错，且不报错 |
| **背景图名** | `bg-rules.mjs` ↔ `demo-assets.mjs` **同名对齐** | 对不上**不报错**，画面静默空白 |
| **音效 id** | `sfx-rules.mjs` ↔ `sfx-catalog.json` | 同上 |
| **音效资产定义** | `sfx-catalog.json` —— JS 侧（`sfx-rules.mjs`）与合成器（`make-sfx.py`）读**同一个文件** | 各写一份 ⇒ 清单与产物对不上，**不报错**（只是「某个 id 永远没声音」） |
| **音效出处与许可证** | `sfx-sources.json` 的 `packs` —— **许可证只写在这一处** | N 处漂移 ⇒ 分发物里带了**没署名/非 CC0** 的素材，而这是**对外**后果 |
| **主线场景名 / 产物路径** | `paths.mjs`（`ROOT` / `SCENE_DIR` / `mainlineSceneName()`）。改名用 `--scene=` 或环境变量 `SCENE` | 散在四个脚本里 ⇒ 改名**必漏一处**，而漏了的那个**读不到就静默跳过**（或报一个与真因无关的错） |
| **切分入口** | `docx-to-mainline.mjs` 的 `chunksOf()`（带无损自检） | 绕过它 = 丢掉「全片每一框都不丢字」这条不变式 |
| **配乐落点** | `bgm-cues.mjs`（`SCENE_CUE` 出厂为空，**由使用者填**） | 空着不填 ⇒ 编译期**明确报错**（这是设计，不是 bug） |
| **文档里的规模数字** | 由 `../verify-repo.mjs` 的**探测器 ⑤**对着实测核（表格行的「规模」格 + 「合计」句；口径 = 本目录下全部 `.mjs` + `.py`） | 先改代码、后回头核文档 ⇒ 提交里带着**已经过期的数字**（这类事至少犯过四次）。★ **别手算，跑 ⑤** |

## 红线

- ❌ **不要另写第二份**切分 / 容量 / 转义 / 锚点实现
- ❌ **不要另写第二份**音效资产表（要加音效 → 改 `sfx-catalog.json` 一处）
- ❌ **音效不要引入非 CC0 素材**。收了 CC-BY 就必须把署名写进游戏内 Staff 页，
  并登记到 `sfx-sources.json` —— **许可证只写这一处**
- ❌ **不要读 SCSS 或文档猜文本框几何** —— 真机量
- ❌ **不要重写 Pixi 舞台 / UI / 特效 / 存档 / 鉴赏 / 流程图** —— WebGAL 已有且更成熟
- ❌ **不要 fork WebGAL 源码** —— 配置与脚本能解决的事不要改源码
- ❌ **不要引入运行时注入**（走协议把拍推上舞台）—— 代价见 `../docs/architecture.md` §二
- ❌ **不要在体检器里把「通道缺失」当「通过」** —— 分不清「没查」和「查过了没问题」的校验器没有用
  （判据：报错为空 + 全量失败 ≒ 通道坏 ⇒ **先查通道，再信结论**）
- ❌ **不要让缺失资源「静默降级」** —— 宁可明确报错（静默降级在 VN 里表现为全场静音 / 画面空白）
- ❌ **不要在文档里手写行数 / 脚本数然后不管它** —— 探测器 ⑤ 会核；对不上就报红。
  **改了代码顺手改数字**，别指望下次通读能想起来（前四次都没想起来）
- ✅ 改进编译器映射、加剧本规范检查、打磨断框与资源规则

## ★★ UI / 外包装（WebGAL 主题的「可改面」）

> ⚠️ **本节由原项目的 UI 外包装流程提炼而来；那批脚本未随本仓提供。**
> 保留是因为**下面这些 WebGAL 事实与坑与具体作品无关、可以直接用**——
> 你要做主题，照表改文件即可，不必复现那套脚本。

**方法论一句话**：规则能算的（模块清单 / 现状实测 / 资产规格 / 落盘路径 / 令牌结构）
应该预先算好，**只把「判断气质」那一件事留给人或模型**。

### 可改面只有这些（`templateLoader.ts` 里写死的）

| 通道 | 能改什么 |
|---|---|
| **官方主题 SCSS（仅 3 个）** | `game/template/UI/Title/title.scss` · `Stage/TextBox/textbox.scss` · `Stage/Choose/choose.scss`。选择器写**未 hash 的组件名**（`.TextBox_main`），会被映射到真实类名 |
| `game/userStyleSheet.css` | **其余所有面**。普通 CSS 文件，**必须用 `[class*="组件名"]`** —— 真实类名是 `_TextBox_main_<hash>_<n>`，写死 hash 会在某次引擎重建后静默失效。★ `build-demo.mjs` 会**幂等维护**这个文件里的章节卡样式块 |
| `game/template/template.json` | `fonts[]` → 注入 `@font-face` + **排到设置字体选项最前（即默认）**；`url` 相对 `game/template/` |
| `game/config.txt` | `Title_img` / **`Game_Logo`（`\|` 分隔多张，启动 Logo 序列）** / `Title_bgm` / `Game_name` / `Game_Key` / `Enable_*` |
| `game/template/assets/` | 主题资产（字体、图标 SVG） |

### ★ 运行时能切的状态（其余都是编译期定的，别设计依赖它）

- **`filmMode:on/off`** ⇒ **一整套没用过的第二皮肤**：换成 `TextBoxFilm`（**名字框与 mini 立绘在源码里被注释掉**）+ `BottomControlPanelFilm`（双语标签）。★ 这是「人戏 / 档案戏」分层的关键手段
- `setTextbox:hide` **只能隐藏**（不是主题切换，`standard`/`imss` 是编译期决定的）
- `setFilter:` **在 4.6.5 里是空实现**（`return createNonePerform()`）—— 名字骗人，别设计依赖它
- `miniAvatar:<id>` / `none`：立绘小头像有无
- `say:… -fontSize=small|medium|large`：逐行三档
- 旁白 vs 对白：DOM 差异 + CSS `:has()`（**不改源码**就能两套字）
- `intro:` 全屏演出（章节卡已用它做 `clip-path` 切片）
- `setVar:` **没有到 CSS 的桥** ⇒ 变量改不了样式

### 踩过的坑

- **卡文不要塞进 JS 模板字符串**：markdown 里到处是反引号，会直接语法报错、且报错位置在几百行之外。⇒ 外置成 `.tpl` 文件 + `@@占位符@@`
- **勘察器的元素匹配不能按「是不是叶子」**：一改 CSS 把文字从隐藏覆盖层挪回父级 div，工具就再也找不到按钮 ⇒ 整轮卡在标题画面（截图全一样）而**看起来像主题没生效**。改用「元素自身文本节点」
- **按文字点按钮要防前缀命中**：「存档」会命中「**快速**存档」（`includes`）⇒ 取文本最短的那个 + 支持精确匹配
- **字体必须子集化 + 改名**：CJK 全量 ~20MB/字重；且**系统里已装同名家族**，不改名浏览器可能直接拿系统字体、我们的子集白做
