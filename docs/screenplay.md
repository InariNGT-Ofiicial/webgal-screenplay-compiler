# 剧本规范与断框

> AVG 有它自己的手艺，**不是通用写作常识**。
> 可机械判定的部分已做成体检器：`compiler/screenplay.mjs`（7 类检查 / 70 项测试）。

---

## 一、核心认知

> **小说靠文字讲故事，AVG 靠画面承载信息，文字只补画面给不了的。**

掌握这一条，下面所有规矩都能推出来。

---

## 二、硬指标

★ 下面的数字**不是拍的**，出自 `compiler/textbox.mjs` ——
那是真机实测出来的文本框几何（内容区 2022×234px、字号 52.48px、字距 5.12px、行高 2.2em）。

| | |
|---|---|
| 每行字数 | **35 全角字**（理论 38，留 10% 余量） |
| 单框行数 | **2 行**（内容高 234px ÷ 行高 115.5px = 2.03） |
| **单框字数** | 设计上限 **56 字**；**物理上限 70 字** |
| 对白 : 旁白 | 7:3 ~ 8:2（作品级） |
| 同框立绘 | ≤3 人 |
| 一画面台词 | **1-3 句，绝不超 4 句不变画面** |

### ★★ 超 70 字不是「难看」，是「丢字」

WebGAL 的 `concatTextLines` 最后一句是 `textArray.slice(0, lineLimit)` ——
超出实装行数的文本**根本不渲染**。

所以 70 是硬底线，`test-split.mjs` 用 `estimateLines` 把每一框都验一遍——
这条断言等价于「上屏不会丢字」。

> ⚠️ **注意与网上通用建议的差异**：不少 AVG 教程写「单行 8-10 字、单框 30-40 字」，
> 那是针对**小字号、窄文本框**的排版。本项目跑的主题实测每行装得下 **35** 字。
> **上限一律以真机实测为准** —— 照搬教程会把一句普通台词切成两三框。

## 三、三条最容易犯的错

1. **「她看起来很生气」是废话** —— 立绘已经换了愤怒表情。**信任美术。**
2. **立绘做不出来的动作，宁可切掉立绘**。保留错误立绘比没有更糟。
3. **别抱怨「一行放不下」** —— 文本框容量限制是最好的节奏工具，断句要在悬念处。

## 四、断框（文本框切分）

唯一实现在 **`text-split.mjs`**（`chooseCut`，一次满足全部约束），
容量来自 **`textbox.mjs`**（真机实测的几何，唯一真源），
测试在 **`test-split.mjs`**（26 项，含全片回归）。

抽成独立模块**就是为了能单测** —— 埋在转换脚本里时，`import` 就会跑完整转换，测不了。

### ★ 不变式 ①（无损）：`splitText(t).join('') === cleanText(t)`

破了不会报错，只会让屏幕上**静默**印出缺空格的词：实测 `M72 LAW 66mm` → `M72LAW 66mm`。

根因是**逐框过 `cleanText`（带 `.trim()`）**，把落在框边界上的空白吃掉了。
⇒ 只在开头整体清一次，框**不再 trim**，靠前导标点规则把边界空白挂到上一框末尾。

校验点在 `chunksOf()`（切分的**唯一入口**），每次转换都印。

### ★ 不变式 ②（装得下）：每一框都必须装得进实装行数

见上文「超 70 字是丢字」。这条等价于「上屏不会丢字」。

### ★ 硬规则：框尾不许是 `，、；：`

一框 = 一个句子；以逗号结尾等于把句子拦腰砍断。

同族还有两条：

- **框尾不许是开引号 / 开括号** —— 一对引号必须同框。
  实测漏了这条：`…名为“`(56) | `X”的谎言帷幕。` —— 引号挂框尾，内容翻页。
- **框尾 / 框首不许是单字虚词**（`的` `了` `是` 这类）。
  规则设计成「无遗憾改进」：**只有存在同样干净且零瑕疵的更靠左切口时才改用它**，
  所以只可能变好。

### 断词率怎么量

拿**切分器自己用的**分词器自测（自洽口径），切口必须落在词边界上。
跨分词器对比可以自己接一个（本项目另有一个用 jieba 口径的度量脚本，未随引擎分发）。

> **口径纪律**：度量工具不能重写策略。只测**真实产物**，不在探针里复刻一套逻辑——
> 否则量的是探针，不是产物。

## 五、编辑层表述：**丢弃**，不是「不渲染」

剧本里常有**编辑层的痕迹**：预告、卷末旗标（「下回预告」「敬请期待」这类）。
它们**不是剧情**，进了游戏会破坏沉浸。

唯一识别实现在 **`editorial.mjs`**，三处共用（转换器丢弃 + 编译期拦截 + 测试）。

★ **不能按「被【】包住」一刀切** —— 叙事内方括号很多（`【快讯】` 这类是真内容）。

★ 也不能拿「待续」当关键词：`旁白：队长沉默地带领手下回到指挥车。`
里就藏着「下回」（手**下回**到）—— 按子串搜会误杀一句完全正常的旁白。

⇒ 词表只收**不会出现在剧情里**的完整词，且要求**整行**匹配。

★ **表述是「丢弃」不是「不渲染」**：被丢弃的内容不该出现在任何产物里；
只活在渲染层的过滤，等于下游还拿着脏数据。
